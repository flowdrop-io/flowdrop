# Archived — historical reference only

This Astro + Starlight documentation site (formerly **docs.flowdrop.io**) is
**no longer maintained** as of FlowDrop 2.x.

Documentation now lives in the unified Mintlify site
**[`flowdrop-io.docs`](https://github.com/flowdrop-io/docs)** — symlinked into
this monorepo at `.docs/`. That site is the single source of truth for FlowDrop
documentation going forward.

This directory is retained only so its content can be referenced while the
Mintlify port is completed. It is **safe to delete** once the port is done.

Do not add new content here.
