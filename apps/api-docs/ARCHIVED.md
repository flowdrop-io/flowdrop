# Archived — historical reference only

This Redocly API-reference site (formerly **api.flowdrop.io**) is **no longer
maintained** as of FlowDrop 2.x.

The API reference now lives in the unified Mintlify site
**[`flowdrop-io.docs`](https://github.com/flowdrop-io/docs)** (symlinked at
`.docs/`), which renders the OpenAPI spec natively. The spec source itself
remains canonical at `libs/flowdrop/api/v1/` — only the _rendering_ moved.

This directory is retained for historical reference and is **safe to delete**
once the Mintlify API reference is verified.

Do not add new content here.
