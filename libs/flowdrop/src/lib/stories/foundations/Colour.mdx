# Colour

Most of the editor is neutral: surfaces, text and thin lines in greys. Colour appears only where
it tells you something:

- the **primary** colour for the one main action of a view;
- the **accent** for selection, keyboard focus and things that are running;
- **status** colours only where something has a status.

If everything is coloured, nothing stands out. Keep new UI neutral and let these few colours
carry the meaning.

Values come from the skin selected in the toolbar. **set by skin** marks a value the skin
chooses instead of the library default.

## Node and edge colours

Node categories get their own hues (`--fd-node-blue`, `--fd-node-emerald`, …), and wires use
`--fd-edge-*`. These are editor-part tokens: change them only to recolour nodes or wires. Run
status has its own roles, see [Run status](?path=/docs/foundations-run-status--docs).
